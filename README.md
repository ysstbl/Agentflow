AgentFlow is a multi-agent AI assistant built using LangGraph, LangChain, Gemini, and Tavily Search. The system intelligently classifies user queries, routes them to specialized agents, retrieves information from documents and live web sources, and synthesizes the results into a unified response. By combining agent orchestration, Retrieval-Augmented Generation (RAG), and real-time search capabilities, the project demonstrates the design and implementation of scalable AI workflows for complex information retrieval and reasoning tasks.
Tech Stack:
-Python
-LangGraph
-LangChain
-Gemini
-Tavily Search
-RAG Architecture
-Pydantic
-HTTPX
